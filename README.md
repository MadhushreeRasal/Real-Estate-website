# 🏠 Real Estate Website

A modern and responsive real estate website designed to showcase properties and real estate services through a clean, professional, and user-friendly interface.

🔗 **Live Website:** [Real Estate Website](https://madhushreerasal.github.io/Real-Estate-website/)

## ✨ Features

* 📱 Responsive design for different screen sizes
* 🏡 Clean and modern real estate interface
* 🏢 Property-focused sections
* 🌾 Support for residential, commercial, and agricultural property categories
* 📋 Property and service information sections
* 🧭 Easy and intuitive navigation
* 🎨 Professional visual design

## 🛠️ Technologies Used

* **HTML5**
* **CSS3**
* **JavaScript**
